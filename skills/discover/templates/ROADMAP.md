# Roadmap

Each milestone is a vertical slice: it runs and is testable on its own.
The pipeline builds one milestone per run and ticks it (`[x]`) after it is merged into the main branch.
Keep the heading format exactly `## [ ] M<n> - <title>`: the pipeline parses it.

## [ ] M1 - <Skeleton and first working slice>
ACs: AC-1
Scope: project skeleton, test runner wired up, <smallest end-to-end behavior>.

## [ ] M2 - <title>
ACs: AC-2, AC-3
Scope: <...>
